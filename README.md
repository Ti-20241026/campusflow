# CampusFlow · 项目网站

**面向在校大学生的一站式校园生活服务 App** —— 人机交互（HCI）实验课小组项目。

CampusFlow 把食堂排队与菜单、图书馆座位与自习室、打印店排队、快递代取、校园活动与讲座报名、
校园卡与费用查询等分散在多个 App、公众号与群聊里的信息，汇总到一个界面中，
并提供「同校同学互助代办（跑腿）」与「课表／空闲时间联动提醒」。
